📖 PANDUAN KONEK HP

LANGKAH 1: BUKA HALAMAN GAME DI HP

Pastikan layar utama (PC/Laptop) dan HP membuka link web yang sama. *Catatan Penting: Jika kamu menjalankan game ini di dalam jendela preview editor (bukan link https://... publik), kamera HP belum bisa membuka halaman preview lokal secara langsung sebelum file HTML ini di-upload/di-host ke web (misal Netlify, Vercel, atau GitHub Pages).

LANGKAH 2: SCAN QR ATAU MASUKKAN KODE PIN
  • Cara A (Scan Kamera HP): Jika game sudah online (URL https://...), arahkan kamera HP ke QR Code di layar PC, lalu buka linknya. HP otomatis masuk ke mode stik!
